## 一、先锁定参考环境

### 1.1 语言：选简体中文

| 候选 | 结论 |
|---|---|
| 简体中文 | **采用**。测试名片中 6 张中文 + 6 张双语均为简体；CamCard 简体版对中英混排识别最好；自己的 App 也用中文界面 |
| 繁体中文 | 否。与测试名片不符，且会让字段标签（手机/邮箱）与自制 App 不一致 |
| 英语 | 否。无法覆盖中文名片识别这一核心考点 |

操作：CamCard「设置 → 语言」改为简体中文；若 App 跟随系统语言，则把 iOS 系统语言一并设为简体中文，避免界面中英混排。

记录两项：**App 界面语言**、**iOS 系统语言**。

### 1.2 固定版本（iOS 无法降级，只能冻结）

1. 设置 → App Store → 自动下载 → **关闭「App 更新」**。
2. 不要手动点 App Store 里的「更新」按钮。
3. CamCard 内部弹出的升级提示一律选「以后再说」。
4. 设置 → 通用 → 软件更新 → 自动更新 → **关闭「下载 iOS 更新」与「安装 iOS 更新」**（系统升级会让 Xcode 与参考环境失配）。
5. 把版本证据截图存档（见清单 00）。

> iOS 不提供安装历史版本的能力，一旦升级**无法回退**。所以关掉自动更新是唯一的办法。
> 每次进机房前核对一次版本号是否与记录一致；如已变化，必须在报告中说明并重新采集。

### 1.3 查版本号的三个位置（建议都查，互相印证）

| 方法 | 路径 | 说明 |
|---|---|---|
| App Store 产品页 | App Store → 搜索 CamCard → 向下滚动到「新功能」 | 标题处直接写「版本 x.y.z · 日期」，还能看到更新历史 |
| 手机储存详情 | 设置 → 通用 → iPhone 储存空间 → CamCard | 页面内显示版本号 |
| App 内关于页 | CamCard → 我的 / 设置 → 关于 | **最准确**，是真正在运行的版本 |

记录：**版本号 + 构建号（若有）+ 查询日期**。

## 二、拍摄方法（很重要，决定了对比是否成立）

1. **用你自己的测试名片**，不要用真实名片。
   把 `references/test-images/` 里的图片显示在笔记本屏幕上，用 iPhone 拍摄——这样参考 App 和你自己的 App 输入完全相同，截图对比才成立。
2. 涉及"识别结果"的截图，统一用这几张，便于逐字段对齐：

| 用途 | 用哪张测试名片 |
|---|---|
| 主流程（拍摄 → 识别 → 保存） | `zh_01` |
| 缺字段验证（T09 不虚构 Website） | `ms_01` |
| 多电话 / 多 Email（T10） | `mp_01` |
| 倾斜、阴影、检测与校正（T06） | `px_02` 或 `px_04` |
| 竖版版式 | `vt_01` |
| 复杂背景 | `cx_01` |

3. **权限弹窗用截图，不要指望录屏**。系统权限弹窗可能不出现在录屏里，用截图一定能拿到。
4. 录屏：录一段**完整的端到端流程**（空名片夹 → 扫描 → 拍摄 → 校正 → 识别 → 人工修改 → 保存 → 返回列表 → 打开详情 → 搜索 → 导出），再补 2～3 段关键片段（校正、人工修改、导出）。
5. 别一次拍完就删原始素材，全部保留到项目结束。
