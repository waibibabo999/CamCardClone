# 录屏指南（参考 App 行为 Ground Truth）

静态截图能证明"界面长什么样"，但证明不了"点下去会发生什么"。作业要求的是**可观察行为等价**，所以流畅的操作录像是最关键的证据之一。

---

## 一、怎么录（iPhone 屏幕录制）

1. 先确认控制中心里有「屏幕录制」：设置 → 控制中心 → 把「屏幕录制」加进去（一般默认已加）。
2. 从屏幕右上角下滑打开控制中心 → **长按**屏幕录制按钮 → 在弹出的面板里打开「麦克风」→ 点「开始录制」。
3. 顶部状态栏或灵动岛变成红色，表示正在录制。
4. 结束录制：点击灵动岛上的红色区域，或回到控制中心点红点。
5. 视频会自动保存到「照片」App 的「录屏」相簿。

### 录制前先做四件事

- 打开**勿扰模式**（设置 → 专注模式），避免微信、短信通知弹进画面。
- 打开**竖屏锁定**，中途不要旋转手机。
- 把要拍的测试名片图片先显示在笔记本屏幕上并缩放到合适大小（建议用 `zh_01` 作为主线素材）。
- 确认 CamCard 已登录、语言为简体中文、相机与相册权限已授权。

### 要不要开麦克风

建议开。边操作边念一句"现在点的是拍摄""这里我要把邮箱改回去"，写报告时你能准确回忆起每段在做什么，也省得反复看录像。

## 二、录哪些（1 段完整 + 5 段片段）

### 片段 01：端到端主流程（必录，一次到底，不剪辑）

这一段最重要，**中间不能跳步**，否则就失去"端到端闭环"的证明力。预计 3～5 分钟。

```
打开 App（停在名片夹）
  → 点底部中央的相机按钮
  → 单张拍摄，对准 zh_01 并等自动检测框出现
  → 按快门
  → 校正页：拖动四角 + 旋转
  → 确认，等待识别
  → 识别结果页（展示自动填好的字段）
  → 人工修改一个字段（见片段 03）
  → 保存
  → 回到名片夹，确认新名片出现
  → 打开详情页
  → 搜索"张"
  → 返回
```

### 片段 02：区域检测与校正（20～40 秒）

只录"检测框出现 → 手动拖四角 → 旋转 → 确认"这一段。用 `px_02`（倾斜、有阴影）效果最好，能看出参考 App 怎么处理倾斜名片。

### 片段 03：人工校正（30 秒）

用 `zh_02`（它的邮箱会被识别错成 `iijlngyi`）。录"改前 → 编辑 → 改后 → 保存"，这是 T11 的直接证据。

### 片段 04：删除名片（20 秒）

详情页 → 右上「⋯」→ 删除 → 确认弹窗（注意录到那句"30 天内可到官网回收站恢复"）→ 返回列表，确认名片消失。

### 片段 05：导出到通讯录（30 秒）

详情页 → 「保存到通讯录」→ 通讯录权限弹窗 → 允许 → 完成。录完后回到详情页，左下角会变成「已存」，把这一帧停住拍个静态图也行。

### 片段 06：非名片输入（可选，但很有价值）

对着空白纸或桌面随意拍一张，录下结果页——参考 App 会**输出一堆错误字段**，而不会提示"无法识别"。

这段录像是"参考 App 不存在识别失败路径"的唯一直接证据，写报告时很有用。

## 四、文件太大怎么办

录屏体积很大，几分钟就可能几百 MB，而 **GitHub 单个文件上限是 100 MB**。按下面的顺序处理：

1. 片段 02～06 一般都很短，直接提交。
2. 端到端主流程如果超过 100 MB：在「照片」里用 分享 → 存储到"文件" 时选择较低分辨率，或先用系统工具裁掉开头的准备过程。
3. 仍然过大：把完整版放网盘，在报告里写明链接与文件名，仓库里只放压缩版或片段。

⚠ 不要把 `.mp4` 加进 `.gitignore`——录屏是作业要求的行为证据，必须随仓库提交；只是要控制单文件体积。

## 五、录完的自检

- [ ] 画面里能看到顶部录制中的红色指示（证明是真实操作而非拼接）
- [ ] 主流程中间没有跳步
- [ ] 每段开头能看清起始状态、结尾能看清结果状态
- [ ] 录到了至少一次系统权限弹窗或错误提示
- [ ] 文件名按上表命名，放在 `recordings/` 下
