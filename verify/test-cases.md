## 二、每个测试的详细说明

### T01 First Launch

- 前置：App 无数据
- 步骤：启动 App
- 预期：
  - 显示空名片夹
  - 显示“扫描名片”入口
  - 不崩溃

### T02 Enter Scanner

- 前置：名片夹
- 步骤：点击“扫描名片”
- 预期：
  - 进入相机页
  - 若权限未申请，先申请权限

### T03 Permission

- 前置：首次进入扫描
- 步骤：
  1. 允许相机权限
  2. 再次进入扫描
  3. 拒绝相机权限
- 预期：
  - 允许 → 显示相机预览
  - 拒绝 → 显示权限说明与“前往设置”入口
  - 不崩溃

### T04 Capture

- 前置：相机页
- 步骤：拍摄一张标准名片
- 预期：
  - 生成当前帧图像
  - 进入预览
  - 可确认、重拍、取消
  - 确认后进入检测

### T05 Import

- 前置：相机页
- 步骤：点击相册导入，选择一张名片
- 预期：
  - 打开 PhotosPicker
  - 选择后进入预览
  - 确认后进入检测

### T06 Card Boundary Detection

- 前置：预览页
- 步骤：确认图片
- 预期：
  - 自动检测名片边界
  - 显示四边形区域
  - 检测失败时显示“未检测到名片”并提供手动调整

### T07 OCR

- 前置：校正确认
- 步骤：进入 OCR
- 预期：
  - 显示处理中
  - 完成后显示 OCR 原始文本
  - 原始文本保存到 ocrRawText

### T08 Structured Extraction

- 前置：OCR 完成
- 步骤：进入字段解析
- 预期：
  - 姓名、公司、职位、电话、Email 分类正确
  - 无法确认字段为 nil

### T09 Missing Field

- 前置：名片无 Website
- 步骤：进入字段解析
- 预期：
  - website 为 nil
  - 不得虚构 Website

### T10 Multiple Phones

- 前置：名片含 Mobile / Office / Fax
- 步骤：进入字段解析
- 预期：
  - mobile、phone、fax 分别正确
  - 不混淆

### T11 Manual Correction

- 前置：字段解析完成
- 步骤：修改错误字段并保存
- 预期：
  - 修改生效
  - source 变为 user
  - 详情页显示修改后的值

### T12 Save

- 前置：人工校正完成
- 步骤：确认保存
- 预期：
  - 返回名片夹
  - 列表出现新名片
  - 原图、处理图、字段、标签、备注保存

### T13 Detail

- 前置：名片夹有数据
- 步骤：打开名片
- 预期：
  - 显示原图、处理图、全部字段、标签、备注
  - 点击电话可拨号
  - 点击 Email 可发送邮件
  - 点击 Website 可打开浏览器

### T14 Edit

- 前置：名片详情
- 步骤：编辑姓名或公司，保存
- 预期：
  - 页面正确更新
  - updatedAt 更新
  - 持久化后仍为新值

### T15 Search

- 前置：名片夹有数据
- 步骤：搜索姓名或公司
- 预期：
  - 返回正确名片
  - 无结果时显示空状态

### T16 Tag

- 前置：名片夹有数据
- 步骤：创建标签，添加标签，按标签筛选，删除标签
- 预期：
  - 筛选结果正确
  - 删除标签后名片上同步移除

### T17 Delete

- 前置：名片夹有数据
- 步骤：删除名片
- 预期：
  - 名片从列表消失
  - 持久化后仍不在

### T18 Persistence

- 前置：已保存名片
- 步骤：Kill App → Relaunch
- 预期：
  - 名片、原图、修改字段、标签、备注全部保留
  - 打开名片正常

### T19 Export

- 前置：名片详情
- 步骤：导出到系统联系人 / VCF
- 预期：
  - 姓名、公司、职位、电话、Email、地址映射正确
  - 成功显示反馈
  - 失败显示错误

### T20 Exception

- 前置：多种
- 步骤：
  - 拍摄后取消
  - 检测后返回
  - 拒绝权限
  - 无法识别
  - 字段为空保存
- 预期：全部符合规格，不崩溃

## 三、概率性功能评价

使用教师提供的固定名片测试集 + Ground Truth。

对每张名片：
1. 保存 OCR 原始输出
2. 保存字段解析结果
3. 与 Ground Truth 比较
4. 计算字段级准确率
5. 与参考 App 结果对比
6. 分析错误原因
7. 允许人工校正

统计：
- 每字段准确率
- 总体准确率
- 错误类型分布

## 四、测试覆盖要求

- 每个 Reference Test 对应至少一个 XCTest 或 XCUITest 用例
- 单元测试覆盖：Store、ImageStore、FieldParserService、ExportService、状态转换
- UI 测试覆盖：T01–T20
- 回归测试：每次修改后跑全部已有测试
