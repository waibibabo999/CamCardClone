# 需求规格

## 一、功能目标

复刻 CamCard “名片数字化与联系人管理”完整闭环：

名片夹 → 扫描名片 → 拍摄/导入 → 名片区域检测 → 透视/方向校正 → OCR 文字识别 → 联系人字段解析 → 人工确认与修改 → 保存名片 → 名片夹 → 搜索/标签/查看详情 → 联系人导出。

不接受“拍一张照片 → OCR → 显示一段文字”的演示型实现。

## 二、用户场景

1. 用户首次启动 App，看到空名片夹。
2. 用户拍摄一张中文名片，进入识别流程。
3. 用户从相册导入一张英文名片。
4. 用户校正一张倾斜拍摄的名片。
5. 用户对 OCR 结果进行人工修改。
6. 用户保存名片，退出 App 再打开，名片仍在。
7. 用户按公司名搜索名片。
8. 用户给名片添加标签并按标签筛选。
9. 用户将名片导出到系统联系人 / VCF。
10. 用户遇到相机权限拒绝、无法识别、字段为空等异常情况。

## 五、交互列表

- 点击：扫描入口、名片项、按钮、标签、搜索结果
- 拍摄：快门、重拍、取消、确认
- 导入：从相册选择图片
- 拖拽：名片区域四角调整
- 旋转：顺时针 / 逆时针 90 度
- 滑动：列表滚动
- 编辑：字段修改、保存、取消
- 排序 / 标签：添加标签、删除标签、按标签筛选
- 导出：导出到系统联系人 / VCF
- 返回：各页面返回上一级

## 六、输入

- 相机帧
- 相册图片
- 用户手势
- 用户输入字段：姓名、公司、职位、电话、Email、Website、地址、备注
- 标签
- 搜索关键词

## 七、输出

- 名片原图
- 处理后的名片图
- OCR 原始文本
- 结构化字段
- 名片列表项
- 名片详情
- 搜索结果
- 标签筛选结果
- 系统联系人 / VCF 文件
- 保存成功 / 失败提示

## 八、异常情况

- 相机权限拒绝
- 相册权限拒绝
- 无法检测名片区域
- OCR 失败或无结果
- 字段为空
- 多电话号码
- 多 Email
- 用户取消
- 返回上一级
- 删除名片
- 导出失败
- App 被 Kill 后重启

## 九、验收标准

见 `spec/acceptance.md` 与 `verify/test-cases.md`。确定性 T01–T20 必须 100% 通过。概率性 OCR / 字段识别使用固定名片集 + Ground Truth 评价。

## 十、非功能要求

- 不崩溃
- 数据持久化可靠
- OCR 原始输出、字段解析结果、人工修改结果必须可追溯
- 不虚构名片上不存在的信息
- 所有状态转换可测试
- UI 接近参考 App
- 测试可重复运行
- 代码符合 PROJECT_RULES.md

## 十一、明确不包含

登录注册、会员与订阅、支付、广告、云同步、多设备同步、CRM 同步、企业权限、数字名片、QR 交换、AI 企业情报、会议录音、销售漏斗。
