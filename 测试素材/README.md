# 测试素材说明

这个目录里是我为项目准备的 42 张测试名片和对应的 JSON 标准答案。

## 目录

- `名片图片/`：用于相册导入、检测、识别和字段解析测试。
- `标准答案/`：与图片同名的 JSON 文件，记录名片上实际存在的字段。

## 文件命名

| 前缀 | 类别 | 数量 |
|---|---|---:|
| `zh_` | 中文名片 | 6 |
| `en_` | 英文名片 | 6 |
| `bi_` | 中英双语名片 | 6 |
| `cx_` | 复杂 Logo 与背景 | 4 |
| `mp_` | 多电话、多邮箱 | 4 |
| `ms_` | 字段缺失 | 4 |
| `px_` | 倾斜、阴影与杂乱背景 | 8 |
| `vt_` | 竖版与特殊版式 | 4 |

所有姓名、电话、公司和邮箱均为虚构数据，不包含真实个人信息。

## 使用方法

1. 在模拟器中把 `名片图片` 内的图片添加到照片 App。
2. 打开应用，点击拍照按钮，再从相册导入图片。
3. 观察自动检测、校正和字段识别结果。
4. 打开同名 JSON，对比姓名、公司、职位、电话、邮箱和地址。
5. 没有出现在 JSON 中的字段，应用应保持为空。

标准答案格式示例：

```json
{
  "id": "zh_02",
  "name": "李静怡",
  "company": "北京华信医疗科技有限公司",
  "jobTitle": "产品经理",
  "mobile": "139-0022-4567",
  "phone": "010-6688-1234",
  "email": "lijingyi@example.com"
}
```
